# daily_csv — 1조 날짜별 작업 기록

하루에 한 파일 (`YYYY-MM-DD.csv`), 한 줄 = 작업 하나. `index.csv`는 날짜별 요약입니다.
Git 커밋 · PR · 촬영 보고서 · 결정 기록을 바탕으로 2026-11-18에 11-13부터 거슬러 채웠습니다.

| 열 | 내용 |
| --- | --- |
| `date` · `course_day` | 날짜 · 교과10 수업 일차 (11-13은 Day 01 · 02 정리 커밋) |
| `time` | 커밋 시각. 촬영 · 회의처럼 커밋이 없는 일은 대략 (오후 · 저녁 · 촬영 전) |
| `owner` | 사람 번호 **S01~S05만** (실명 쓰지 않음). 여러 명이면 `S01 · S05`, 다 같이 하면 `전원` |
| `category` | 수업 · 회의 · 결정 · 촬영 · 데이터 QA · 코드 · 테스트 · 실험 · 문서 · 이슈 · Git · 할 일 |
| `task` · `result` | 한 일 · 숫자로 남길 결과 |
| `outputs` | 만든 파일 · 폴더 (영상 · 얼굴 이미지는 Git에 없음) |
| `commit` · `pr` | 짧은 해시 (`·`로 여러 개) · PR 번호 (main에 바로 올린 커밋은 빈칸) |
| `status` | 완료 · 진행 중 · 대기 |

## 쓰는 방법
- 그날 마지막에 한 줄씩 추가 (엑셀로 열어도 한글이 깨지지 않게 UTF-8 BOM)
- 촬영한 날은 `촬영` 줄에 개수 · PASS 수 · 누적을 꼭 적기
- 다음 날 할 일은 `할 일` · `대기`로 적고, 끝나면 그날 파일에 `완료`로 다시 적기
