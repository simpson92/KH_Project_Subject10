## 3. 용어

| 용어 | 정의 |
| --- | --- |
| Take | VICON 1회 촬영 단위. 파일 1개 |
| 클립 | 라벨링 대상 파일 1개 (VICON Take 또는 웹캠 영상) |
| 구간 (segment) | 같은 라벨이 이어지는 연속 프레임 범위. `labels.csv`의 1행 |
| 경계 프레임 | 구간이 바뀌는 프레임 |
| Neutral | Take 앞뒤의 기본 자세 (정면, 양팔 내림) |
| 전환 | 한 자세에서 다음 자세로 이동 중인 프레임 |
| 원본 FPS | 리샘플 전 파일의 FPS. VICON = 60 |

- 총 17개 클래스 + 제외 표시 `X`
- A01~A10 = 동작 정의서 Take 1~10, A11~A15 = 추가 +1~+5

| A02 | 홀딩 | Holding | 짧은 동작 | A03 (손 높이) |
| A03 | U파울 | Unsportsmanlike foul | 정지 | A02 |
| A04 | 테크니컬 파울 | Technical foul | 정지 | — |
| A05 | 푸싱 / 볼 없는 상태의 차징 | Pushing / Charging without the ball | 반복 | — |
| A06 | 트래블링 | Travelling | 회전 | A07 |
| A07 | 더블 드리블 | Illegal dribble: Double dribbling | 반복 | A06 |
| A08 | 과도한 팔꿈치 사용 | Excessive swinging of elbow | 반복 | A09, A12 |

## 5. 라벨링 규칙

### 5.1 공통 규칙

| ID | 규칙 |
| --- | --- |
| R-01 | 구간은 클립 전체를 **빈틈·겹침 없이** 덮을 것 |
| R-02 | 프레임 번호는 **원본 FPS 기준, 0부터 시작, end_frame 포함** |
| R-03 | 어느 클래스인지 애매한 프레임은 `X` |
| R-04 | 0.2초 미만 구간 금지 (30FPS 기준 6프레임). 인접 구간에 병합하거나 `X` 처리 |
| R-05 | 동작 의미가 틀린 시도(반대 신호, 중간 멈춤)는 해당 구간 전체 `X`, note에 사유 기입 |
| R-06 | 반복·회전 횟수는 라벨에 영향 없음. 1회라도 의미가 맞으면 인정 |
| R-07 | VICON은 Take당 1회만 라벨링. 2D 투영(전 각도)·좌우 반전 파일은 같은 clip_id 라벨을 상속 |
| R-08 | 좌우 반전해도 라벨 변경 없음 (신호 규칙에 손 지정 없음) |
| R-09 | 신호 의도가 없는 일상 동작은 신호와 모양이 비슷해도 `N00` |
| R-10 | 15개 대상(A01~A15)·C01 밖의 실제 심판 신호도 `N00`. note에 신호 이름 기입 (예: 공격권 방향 지시) |

### 5.2 Take 구간 구조

- 1 Take = 아래 7구간. 시계 정지 없이 바로 신호를 한 Take는 2~4번 생략.

| 순서 | 구간 | label | 시작 프레임 | 끝 프레임 |
| --- | --- | --- | --- | --- |
| 1 | 시작 Neutral | N00 | Take 첫 프레임 | 손목이 움직이기 직전 |
| 2 | 손 들기 이동 | X | 손목이 움직이기 시작 | 팔이 머리 위에서 멈추기 직전 |
| 3 | 시계 정지 유지 | C01 | 손목(9/10)이 머리 중심보다 위에서 멈춘 첫 프레임 | 손목이 내려가기 시작하는 프레임 |
| 4 | 전환 | X | 3번 끝 + 1 | 5번 시작 − 1 |
| 5 | 신호 | A01~A15 | 5.3 기준 | 5.3 기준 |
| 6 | 복귀 | X | 5번 끝 + 1 | 팔이 내려와 멈춘 프레임 |
| 7 | 끝 Neutral | N00 | 6번 끝 + 1 | Take 마지막 프레임 |

> [!warning] 결정 대기 — L1 시계 정지 구간
> 현재 적용값: ① 별도 클래스 C01
> - ① 장점: 실시간 화면에 '시계 정지 → 신호' 순서 표시 가능 / 단점: 클래스 1개 증가
> - ② 장점: 클래스 수 감소 / 단점: 실시간에서 손 들기가 임의 신호로 오인식될 수 있음

> [!warning] 결정 대기 — L2 전환 구간
> 현재 적용값: ① 학습 제외(X)
> - ① 장점: 클래스 경계 명확 / 단점: 실시간 전환 구간은 예측 안정화 규칙(수업 7일차)에 의존
> - ② 장점: 데이터 증가 / 단점: 작업자마다 경계가 달라져 라벨 일치도 하락

### 5.3 동작 유형별 신호 경계

- 자세로 들어가는 이동, 빠져나오는 이동은 신호에 포함하지 않음 (→ `X`).

| 동작 유형 | 대상 | start_frame | end_frame |
| --- | --- | --- | --- |
| 정지 | A01, A03, A04, A10, A15 | 목표 자세 도달 후 움직임이 멈춘 첫 프레임 | 목표 자세가 풀리기 시작하는 프레임 |
| 짧은 동작 | A02, A11, A12 | 핵심 움직임 시작 프레임 | 움직임이 끝나 멈춘 프레임 |
| 반복 | A05, A07, A08, A09, A13 | 1회차 반복 시작 프레임 | 마지막 반복 종료 프레임 |
| 회전 | A06 | 두 주먹이 가슴 앞에서 돌기 시작한 프레임 | 마지막 회전 종료 프레임 |
| 두 단계 | A14 | 5.4 참조 | 5.4 참조 |

짧은 동작의 '핵심 움직임 시작' 기준:

- A02 홀딩: 반대 손이 손목을 잡는 순간
- A11 머리 가격: 손이 머리 쪽으로 올라가기 시작하는 순간
- A12 후킹: 아래팔이 뒤로 빠지기 시작하는 순간

### 5.4 A14 두 단계 신호

> [!success] 결정됨 — L3 (결정 결과 기입 필요)
> 현재 적용값: ① 바닥 가리키기 구간만 A14, 앞 단계(주먹 쥔 팔 들기)는 C01
> - 근거: 앞 단계가 시계 정지와 같은 동작이라 A14에 넣으면 C01과 구분 불가
> - 실시간: 'C01 다음 바닥 가리키기' 순서로 A14 확정
> - ※ 표의 '결정됨'이 ①인지 ②인지 결정 결과 칸에 기입할 것

### 5.5 N00(신호 없음) 수집 규칙

| 출처 | 내용 | 비고 |
| --- | --- | --- |
| Take 앞뒤 Neutral | 5.2의 1·7번 구간 | 라벨링 시 자동 생성 |
| 일상 동작 촬영 | 차렷, 걷기, 박수, 가리키기, 휘슬 불기 | 검토자료 3번 |
| 신호 유사 동작 | 머리 긁기(↔A11), 손가락 가리키기(↔A10·A14), 팔짱(↔A15) | 오인식 방지용. 클래스별 최소 수 회 포함 |
| VICON 현장 추가 Take | E016 선수 가리키며 걷기(↔A10·A14), E017 공격권 방향 지시(대상 외 신호, R-10) | `take_log.csv` `main_label = N00` (매핑 명세 7.4 T-05) |

- 학습 투입 시 N00 수량은 신호 1클래스의 1~2배로 맞춤. 초과분은 평가용으로 보관.

## 6. 산출물 형식: labels.csv

### 6.1 파일 규격

| 항목 | 값 |
| --- | --- |
| 경로 | `data/labels/labels.csv` |
| 인코딩 | UTF-8 (BOM 없음) |
| 구분자 | `,` |
| 헤더 | 필수 (아래 컬럼 순서 고정) |
| 단위 | 1행 = 1구간 |

### 6.2 컬럼 명세

| # | 컬럼 | 타입 | 필수 | 허용값 / 형식 | 설명 |
| --- | --- | --- | --- | --- | --- |
| 1 | clip_id | str | Y | VICON `P###_A###_T##` / 웹캠 `S##_A##_R##` | 클립 식별자 (매핑 명세 파일 이름 규칙) |
| 2 | source | str | Y | `vicon`, `webcam` | 데이터 출처 |
| 3 | person_id | str | Y | `P###`, `S##` | 촬영자. Subject-wise Split 기준 |
| 4 | label | str | Y | 4장 label 목록 | 구간 클래스 |
| 5 | start_frame | int | Y | ≥ 0 | 구간 시작 (원본 FPS) |
| 6 | end_frame | int | Y | ≥ start_frame | 구간 끝 (포함) |
| 7 | start_sec | float | Y | 소수 3자리 | start_frame / fps |
| 8 | end_sec | float | Y | 소수 3자리 | end_frame / fps |
| 9 | fps | int | Y | VICON 60, 웹캠 실측값 | 원본 FPS |
| 10 | labeler | str | Y | 작업자 이름 | 라벨링 담당 |
| 11 | qa_status | str | Y | `PASS`, `RESHOOT`, `EXCLUDE` | 수업 5일차 QA 기준 |
| 12 | note | str | N | 자유 기술 | X 사유 등 |

- Action 번호는 자릿수가 달라도 숫자가 같으면 같은 신호 (`A001` = `A01`).

### 6.3 예시

```csv

P001_A001_T01,vicon,P001,X,42,77,0.700,1.283,60,하민,PASS,손 들기 이동
P001_A001_T01,vicon,P001,C01,78,131,1.300,2.183,60,하민,PASS,
P001_A001_T01,vicon,P001,X,132,159,2.200,2.650,60,하민,PASS,전환
P001_A001_T01,vicon,P001,A01,160,301,2.667,5.017,60,하민,PASS,
```

※ 숫자는 형식 예시임.

## 7. 자동 검증 규칙

- 오류 1건 이상이면 학습 파이프라인 투입 금지.

| ID | 검사 내용 | 심각도 | 위반 시 처리 |
| --- | --- | --- | --- |
| V-01 | 필수 컬럼 누락·빈 값 | 오류 | 수정 후 재검사 |
| V-02 | label이 허용 목록 밖 | 오류 | 수정 |
| V-03 | 같은 clip_id 안에서 구간 겹침 | 오류 | 경계 수정 (R-01) |
| V-04 | 같은 clip_id 안에서 빈틈 (`다음 start ≠ 이전 end + 1`) | 오류 | 경계 수정 (R-01) |
| V-05 | 첫 구간 start ≠ 0 또는 마지막 end ≠ 마지막 프레임 | 오류 | 경계 수정 |
| V-06 | 0.2초 미만 구간 | 오류 | 병합 또는 X (R-04) |
| V-07 | 신호(A01~A15) 구간이 없는 신호 클립 | 경고 | 원본 확인 |
| V-08 | 신호 구간 길이가 같은 label 평균의 0.5배 미만 또는 2배 초과 | 경고 | 원본 재확인 |
| V-09 | start_sec·end_sec가 frame / fps와 불일치 | 오류 | 재계산 |
