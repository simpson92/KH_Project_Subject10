## 2. 회의 안건

| ID | 안건 | 선택지 | 임시 기본값 | 상태 | 담당 | 기한 |
| --- | --- | --- | --- | --- | --- | --- |
| W1 | 촬영 각도 | ① 정면(0°)만 ② 0°/±30°/±60° | ① + 테스트용 사선 소량 | 🟠 논의 중 | TBD | TBD |
| W2 | 일상 동작(박수·가리키기·휘슬) 촬영 | ① 포함 ② 제외 | ① | 🟠 논의 중 | TBD | TBD |
| W3 | 신호 사이 차렷·걷기 구간 | ① 포함 (연속 시나리오) ② 제외 (신호 단위 클립만) | ① 별도 시나리오 클립으로 소량 | 🟠 논의 중 | TBD | TBD |
| W4 | 촬영 규모 (인원 × 반복) | 5장 단계표 참조 | 초기 실험 3명 × 5회 | ⚪ 미정 | TBD | TBD |

- W1~W3은 회의에서 결정 필요. W4는 회의 때 함께 정할 것을 제안함.
- 회의 전 촬영 시에는 **임시 기본값** 적용.

> [!warning] 회의 안건 — W1 촬영 각도 (정면만 vs 여러 각도)
> 임시 기본값: ① 정면만 촬영 + 최종 평가용으로 사선(±30°) 소량
> - ① 장점: 촬영량 1/5, 카메라 1대·고정 위치로 단순. 각도 다양성은 VICON 투영(0°/±30°/±60°)이 담당
> - ① 단점: 실제 데모 카메라가 정면이 아니면 웹캠 데이터로 각도 차이를 검증할 수 없음
> - ② 장점: 실제 환경과 같은 각도별 데이터 확보
> - ② 단점: 촬영량 5배 (카메라 5대 동시 또는 5회 반복)
> - 회의 전 확인: **데모 때 카메라를 어디에 둘지** 먼저 정하면 판단이 쉬움
> - 영향: `01_관절_매핑_명세.md` D3(투영 각도)는 W1과 별개로 유지 가능

> [!warning] 회의 안건 — W2 일상 동작 촬영 (박수·가리키기·휘슬)
> 임시 기본값: ① 포함 (동작당 촬영자 1인 2~3회, 짧게)
> - ① 장점: 실시간에서 박수·가리키기를 신호로 오인식하는 문제 예방 (검토자료 3번)
> - ① 단점: 촬영·라벨링 양 증가
> - ② 장점: 촬영 단순
> - ② 단점: 신호 없음(N00) 데이터가 Take 앞뒤 Neutral만 남아 오인식 위험
> - 특히 손가락 가리키기(↔A10·A14), 머리 긁기(↔A11), 팔짱(↔A15)은 신호와 모양이 비슷해 효과가 큼
> - 영향: `02_라벨링_가이드.md` 5.5 N00 수집 규칙

> [!warning] 회의 안건 — W3 신호 사이 차렷·걷기 구간
> 임시 기본값: ① 포함하되, 신호 단위 클립과 별도로 '연속 시나리오' 클립을 소량 촬영
> - ① 장점: 실제 경기처럼 신호가 띄엄띄엄 나오는 상황 재현 → 실시간 Sliding Window·예측 안정화(수업 7일차) 검증 가능. N00 데이터 확보
> - ① 단점: 클립이 길어지고 라벨링 구간 증가
> - ② 장점: 라벨링 단순 (클립 1개 = 신호 1개)
> - ② 단점: 실시간 연속 입력에서의 오인식을 테스트할 데이터 없음
> - 영향: `02_라벨링_가이드.md` 5.2 구간 구조 (연속 시나리오는 클립 1개에 신호 여러 개)

## 3. 결정 사항

| ID | 결정 내용 | 상태 | 비고 |
| --- | --- | --- | --- |
| W5 | 손 드는 신호는 **오른손으로 통일** | ✅ 결정됨 | 시계 정지(손 들기)와 한 손 신호 모두 오른손. 왼손잡이도 오른손으로 촬영 |
| W6 | 손 들기(시계 정지)는 **별도 클래스로 라벨링** | ✅ 결정됨 | `02_라벨링_가이드.md` L1 ① (C01) 확정 |

> [!success] 결정됨 — W5 오른손 통일
> - 시계 정지(손 들기), 한 손으로 하는 신호는 모두 오른손으로 수행
> - 왼손 데이터는 촬영하지 않고 좌우 반전으로 생성 (`01_관절_매핑_명세.md` M-09~M-11)
> - 촬영 중 왼손을 쓴 시도는 RESHOOT 처리 (10장)

> [!success] 결정됨 — W6 손 들기 별도 라벨링
> - 모든 신호 Take에 '손 들기 → 신호' 순서를 포함해 촬영
> - 손 들기 구간은 C01, 신호 구간은 A01~A15로 따로 라벨링
> - 손 모양: 파울 = 주먹, 바이올레이션 = 손바닥 (동작 정의서 기준). 단, 라벨은 둘 다 C01

## 4. 촬영 대상

| 구분 | 내용 | 촬영 여부 |
| --- | --- | --- |
| 신호 | A01~A15 (동작 정의서 최종 10개 + 추가 5개) | 필수 |
| 시계 정지 | 오른손 들기. 모든 신호 Take 앞에 포함 | 필수 (W6) |
| 일상 동작 | 박수, 손가락 가리키기, 휘슬 불기, 머리 긁기, 팔짱 | W2 결정에 따름 |
| 연속 시나리오 | 차렷 → 걷기 → 신호 → 차렷 → 걷기 → 신호 … | W3 결정에 따름 |

## 5. 촬영 규모

- 근거: 'YOLO Pose COCO 17과 MediaPipe Pose 33 비교' 문서의 단계별 수집 예시 (15개 동작 기준)

| 단계 | 인원 × 신호 × 반복 | 신호 클립 수 | 용도 |
| --- | --- | --- | --- |
| 기능 작동 확인 | 2명 × 15 × 3회 | 90 | 파이프라인 동작 확인 |
| 초기 모델 실험 | 3명 × 15 × 5회 | 225 | **W4 임시 기본값** |
| 권장 기초 실험 | 5명 × 15 × 5회 | 375 | 목표 |
| 성능 개선 실험 | 10명 × 15 × 5회 | 750 | 여유 시 |

- 촬영 인원 중 **1~2명은 테스트 전용**으로 지정, 학습에 사용 금지 (수업 5일차 Subject-wise Split)
- 테스트 전용 인원은 촬영 전에 미리 지정해 `person_id`로 관리
- 일상 동작(W2)·연속 시나리오(W3)는 위 신호 클립 수와 별도

## 6. 촬영 환경 사양

- 측정값은 모두 촬영 로그에 기록. `01_관절_매핑_명세.md` 7.3의 `camera` 값(VICON 투영용)으로 그대로 사용

| 항목 | 기준 | 비고 |
| --- | --- | --- |
| 카메라 | 스마트폰 IP Webcam (수업 1일차 방식) | 기종 기록 |
| 해상도·FPS | 촬영 시작 전 고정 (예: 1280×720, 30FPS) | 촬영 중 변경 금지. 실측값 기록 |
| 카메라 높이 | 촬영자 가슴~어깨 높이 (약 1.2~1.5 m) | 실측값 기록 |
| 촬영 거리 | 머리 위로 든 손부터 발끝까지 화면 안에 들어오는 거리 (약 3~4 m) | 실측값 기록. 바닥에 서는 위치 테이프 표시 |
| 카메라 각도 | W1 결정에 따름 | 정면 = 촬영자 몸 정면과 카메라가 마주 봄 |
| 배경 | 단색 벽, 화면 안에 다른 사람 없음 | 다른 사람 등장 시 RESHOOT |
| 조명 | 역광 금지, 실내 조명 고정 | |
| 복장 | 몸 윤곽이 보이는 옷, 배경과 대비되는 색 | 헐렁한 옷·긴 소매 가운 금지 |
| 촬영자 위치 | 화면 가로 중앙, 상하 여백 확보 | partial_body 방지 (수업 2일차) |

## 7. 촬영 절차

### 7.1 전체 흐름

| 단계 | 작업 | 산출물 |
| --- | --- | --- |
| S-1 | 촬영 환경 설치·측정 (6장) | 촬영 로그 헤더 값 |
| S-2 | 시험 촬영: 1명이 신호 3~4개 촬영 | 시험 클립 |
| S-3 | 시험 클립 품질 확인: 수업 2일차 방식으로 Keypoint Confidence 확인 (10장 기준) | 통과 시 본 촬영 진행 |
| S-4 | 본 촬영: 촬영자별 A01~A15 × 반복 횟수 | 신호 클립 |
| S-5 | (W2) 일상 동작 촬영 | 일상 동작 클립 |
| S-6 | (W3) 연속 시나리오 촬영 | 시나리오 클립 |
| S-7 | 촬영 직후 재생 확인 → RESHOOT 즉시 재촬영 | 촬영 로그 result |

### 7.2 신호 클립 1개 구성

| 순서 | 구간 | 시간 | 라벨 (02 문서) |
| --- | --- | --- | --- |
| 1 | 차렷 (Neutral) | 약 2초 | N00 |
| 2 | 오른손 들기 → 유지 | 약 1~2초 | C01 |
| 3 | 신호 수행 | 동작 정의서 기준 | A01~A15 |
| 4 | 차렷 복귀 | 약 2초 | N00 |

- 1클립 = 신호 1회. 반복은 클립을 나눠 촬영 (`R01`, `R02` …)
- 시작·끝 차렷 2초는 라벨 경계를 잡기 쉽게 하고 N00 데이터로도 사용

### 7.3 동작 변형 배분 (반복 5회 기준)

| 반복 | 변형 | 근거 |
| --- | --- | --- |
| R01 | 보통 속도·보통 크기 | 기준 |
| R02 | 보통 속도·보통 크기 | 기준 |
| R03 | 빠르게 | 검토자료 2번 (실제 심판은 더 빠르고 짧음) |
| R04 | 느리게 | 검토자료 2번 |
| R05 | 크게 또는 작게 (촬영자별 번갈아) | 검토자료 2번 |

- 반복 3회 단계면 R01 보통, R02 빠르게, R03 작게
- 변형 내용은 촬영 로그 `variation` 컬럼에 기록

### 7.4 헷갈리는 짝은 연속 촬영

- 검토자료 4번 대응. 아래 짝은 촬영 순서를 붙여서 차이를 크게 연기

| 짝 | 구분 포인트 (동작 정의서) |
| --- | --- |
| A06 트래블링 ↔ A07 더블 드리블 | 두 손 붙어서 원 운동 ↔ 두 손 떨어져 위아래 교차 |
| A08 과도한 팔꿈치 ↔ A09 샷클락 | 팔꿈치를 옆·뒤로 휘두름 ↔ 손끝이 어깨에 닿음 |
| A02 홀딩 ↔ A03 U파울 | 손목 잡고 아래로 ↔ 머리 위에서 잡기 |
| A09 샷클락 ↔ A11 머리 가격 | 손이 어깨 ↔ 손이 머리 |
| A08 과도한 팔꿈치 ↔ A12 후킹 | 어깨 높이 ↔ 골반 높이 |

### 7.5 일상 동작 (W2 포함 시)

| 코드 | 동작 | 반복 | 비고 |
| --- | --- | --- | --- |
| D01 | 박수 | 2~3회 | |
| D02 | 손가락으로 가리키기 | 2~3회 | A10·A14와 혼동 방지 |
| D03 | 휘슬 불기 | 2~3회 | 손을 입 쪽으로 |
| D04 | 머리 긁기 | 2~3회 | A11과 혼동 방지 |
| D05 | 팔짱 끼기 | 2~3회 | A15와 혼동 방지 |

- 라벨은 모두 N00 (신호 의도 없음)

### 7.6 연속 시나리오 (W3 포함 시)

- 구성 예: 차렷 3초 → 걷기 5초 → 손 들기 → 신호 → 차렷 3초 → 걷기 5초 → 손 들기 → 신호 …
- 클립 1개에 신호 3~4개, 1~2분 이내
- 신호 순서는 촬영 로그 `note`에 기록 (라벨링 시 참고)
- 용도: 실시간 Sliding Window·예측 안정화 테스트 (학습보다 평가 중심)

## 8. 파일 이름 규칙

| 종류 | 형식 | 예시 |
| --- | --- | --- |
| 신호 클립 | `S##_A##_R##.mp4` | `S03_A05_R02.mp4` |
| 일상 동작 클립 | `S##_D##_R##.mp4` | `S03_D01_R01.mp4` |
| 연속 시나리오 | `S##_SC##.mp4` | `S03_SC01.mp4` |
| 시험 촬영 | `TEST_S##_A##_R##.mp4` | `TEST_S01_A01_R01.mp4` |
| 촬영 로그 | `webcam_log.csv` | `data/raw/webcam/webcam_log.csv` |

- `S##` = 촬영자 ID (01부터). VICON 촬영자 `P001`과 같은 사람이면 로그 `note`에 기록
- 저장 위치: `data/raw/webcam/`

## 10. 품질 기준과 재촬영

### 10.1 시험 촬영 통과 기준 (S-3)

| ID | 기준 | 확인 방법 |
| --- | --- | --- |
| Q-01 | 모든 프레임에서 사람 1명 검출 (`people = 1`) | 수업 2일차 `10_pose_video_quality.py` |
| Q-02 | 오른팔(6·8·10번) 평균 Keypoint Confidence ≥ 0.50 | 같은 스크립트의 keypoints CSV |
| Q-03 | 손 든 상태에서도 손목이 화면 안 | 영상 확인 |
| Q-04 | 발목(15·16번)이 화면 안 | 영상 확인 |

- 하나라도 실패하면 거리·높이·조명 조정 후 S-2 재실시

### 10.2 RESHOOT 기준 (S-7)

| ID | 상황 |
| --- | --- |
| RS-01 | 왼손으로 손 들기 또는 한 손 신호 수행 (W5 위반) |
| RS-02 | 손 들기(시계 정지) 생략 (W6 위반) |
| RS-03 | 다른 신호를 하거나 중간에 멈춤 (동작 의미 오류) |
| RS-04 | 몸 일부가 화면 밖으로 나감 |
| RS-05 | 화면에 다른 사람 등장 |
| RS-06 | 영상 끊김·심한 흔들림 |
| RS-07 | 시작·끝 차렷 구간이 1초 미만 |

- 속도·크기 같은 개인차는 RESHOOT 사유 아님 (VICON 1일차 RETAKE 기준과 같음)
