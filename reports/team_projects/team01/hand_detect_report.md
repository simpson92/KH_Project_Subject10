## 1. 질문

강사님 3·4일차 문서는 1팀에 **YOLO Pose + MediaPipe Hand Landmarker(손당 21점)** 를 추천함.
팀은 D1에서 1단계를 YOLO만으로 정했으므로, 손을 추가하기 전에 아래를 숫자로 확인함.

1. 지금 촬영 조건(폰 세로 · 전신)에서 손 21점을 얼마나 찾는가?
2. 화면 전체에 돌리는 것과 손목 주변만 잘라서 돌리는 것 중 무엇이 나은가?
3. 사람이 작게 찍히면(= 멀리서 찍으면) 얼마나 떨어지는가? → 본 촬영 거리·해상도 기준

## 2. 방법

| 항목 | 값 |
| --- | --- |
| 데이터 | 스모크 100개 (S01~S05 × A03 U파울 · A05 푸싱 × 10회), 1080×1920 세로 |
| 손목 위치 | YOLO Pose(`yolo11n-pose`) 대표 인물(D6 가장 큰 BBox)의 원본 손목 좌표 |
| 표본 | 5 Frame마다 1장 → 2,811 Frame × 좌/우 = 5,622 손목 (YOLO 손목 conf ≥ 0.50 전부 통과) |
| 손 모델 | MediaPipe Hand Landmarker (Tasks API, IMAGE 모드, 최대 2손, 검출 기준 0.5) |
| crop 방식 | 손목 중심으로 한 변 = 어깨 폭 × 1.5 정사각형을 잘라서 검출 |
| full 방식 | 화면 전체에 검출 (비교용) |
| 같은 손 판정 | 손 0번 점(WRIST)과 YOLO 손목 거리 ≤ 어깨 폭 × 0.75. 좌·우 crop이 같은 손 하나를 잡으면 가까운 손목만 인정 |
| 화면 배율 | 1.0 · 0.5 · 0.33 · 0.25 (어깨 폭 중앙값 221 · 110 · 73 · 55 px) |

- 검출률 = 손목이 믿을 만한 Frame 중 그 손목의 손을 찾은 비율
- "검출"은 손을 찾았다는 뜻. 손가락 21점의 위치가 정확한지는 이 실험에서 보지 않음

## 4. 해석

1. **손 정보는 얻을 수 있음.** 손바닥이 앞을 향하는 푸싱은 92%, 손이 겹치는 U파울도 Frame마다 손 하나 이상은 96% 찾음.
2. **crop이 화면 전체보다 확실히 나음** (+13~18%p). 사람별로는 차이가 더 큼 (full 1.0에서 S01 U파울 39%, S05 U파울 34%).
   → 2단계 구조는 "YOLO 손목 위치 → 손목 주변 crop → Hand Landmarker" 로 잡는 것이 맞음 (비교 문서 하이브리드 구조와 같음).
3. **해상도는 지금 병목이 아님.** 어깨 폭 55 px(배율 0.25)까지 crop 검출률이 1~2%p만 떨어짐. 40 px 미만은 50%이지만 표본 24개라 참고만.
4. **진짜 병목은 손이 가려지는 것.** U파울은 한 손이 다른 손목을 잡는 가운데 구간에서 61%로 떨어지고, 손이 하나만 보이는 경우가 12%.
   S01 영상 일부를 눈으로 확인하니 긴 소매가 손을 덮는 Frame, 팔을 올리는 순간 흔들린 Frame에서 손을 못 찾았음.

## 5. 제안 (회의 안건)

| 안건 | 제안 | 근거 |
| --- | --- | --- |
| D1 | 2단계 = **②-b YOLO + Hand Landmarker(crop)** 로 준비. 1단계 RF(38-D/48-D)와 같은 데이터로 E-06 비교 | 3.1 · 4-1 · 4-2 |
| W 촬영 조건 | 어깨 폭 **60 px 이상** 찍히게 (여유 포함). 가로 1080p · 전신이면 충분할 것으로 예상 → 시험 촬영(S-3)에서 확인 | 3.2 |
| W 촬영 조건 | **소매 걷기 · 손목이 드러나는 옷**, 밝은 조명(흔들림 줄이기) | 4-4 |
| 손 Feature 설계 | 손이 안 보이는 Frame이 반드시 생김 → 손 Feature마다 **찾음/못 찾음 표시 열**을 같이 두고, 값을 임의로 채우지 않기 (VICON conf 1.0 금지와 같은 원칙) | 3.4 |
| 손 Feature 설계 | 양손이 겹치는 신호(U파울 등)는 "양손 각각"보다 "보이는 손" 기준 Feature를 검토 | 3.4 양손 50% |

## 6. 한계

- 스모크 2신호만 확인. 손 모양이 핵심인 신호(A04 · A05 · A09 · A10 · A11 — `01` 문서 6.2)는 본 촬영 후 다시 확인해야 함
- 손 검출만 봤고, 손가락 21점의 위치 정확도는 보지 않음 (손가락 굽힘·손바닥 방향 Feature는 별도 검증 필요)
- 손 모델: 공식 `hand_landmarker.task` 대신, mediapipe 0.10.21 패키지에 들어 있는 같은 계열 모델(palm_detection_full + hand_landmark_full)을 Tasks API 형식으로 묶어 실행함. 공식 파일로 다시 돌리면 수치가 조금 다를 수 있음 (같은 crop 75장 비교에서 mediapipe 버전 차이로 검출 10장 ↔ 8장)
- 화면 배율 실험은 원본을 줄인 것이라 실제로 멀리서 찍은 영상(흐림·압축)과는 다를 수 있음
- 처리 시간(참고): crop 1장당 약 10 ms, 화면 전체 약 26 ms (CPU 2코어 환경). 실시간 15 FPS(프레임당 ≤ 66 ms)에 양손 crop 2번이 들어가는지는 팀 PC에서 다시 측정 필요
